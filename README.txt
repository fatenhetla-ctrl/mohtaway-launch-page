ملفات صفحة التعريف المجانية لتطبيق محتواي

- index.html: صفحة تعريف عربية متجاوبة.
- privacy.html: مسودة سياسة خصوصية تحتاج مراجعة قبل النشر.

قبل نشر الموقع:
1. أضف رابط تنزيل APK الحقيقي إلى زري التنزيل في index.html بدل href="#".
2. راجع ميزات التطبيق وممارسات البيانات الفعلية، وأكمل سياسة الخصوصية.
3. أضف بريد تواصل صحيحًا في privacy.html.
4. ارفع الملفين إلى خدمة استضافة صفحات ثابتة مجانية، ثم شارك رابط الموقع الناتج.

لا تتضمن هذه الحزمة ملف APK أو استضافة عامة جاهزة.
